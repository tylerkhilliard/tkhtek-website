# TKH Tek Website

The official website for **TKH Tek** and **SpectraLens**, built with native web standards and hosted via GitHub Pages at [tkhtek.com](https://tkhtek.com).

## Overview

- **`index.html`**: Product showcase for SpectraLens highlighting assistive color tools, hardware-accelerated processing, and App Store direct links.
- **`studio.html`**: Engineering tenets, studio philosophy, and active research initiatives within the TKH Tek Lab.
- **`privacy.html`**: Zero-knowledge data policy and App Store compliance documentation.
- **`style.css`**: Shared dark-mode design system, typography, and responsive layouts.
- **`CNAME`**: Custom domain routing for `tkhtek.com`.

## Development

The site is built with vanilla HTML5 and CSS—no dependencies, build pipelines, or node packages required.
